# Security Policy

Jalvoro OS is an early-stage project. It is not production-ready, and no security certification is claimed.

## Reporting a vulnerability
Do not publish exploit details, credentials, or sensitive data in a public issue. Until a dedicated private security-reporting channel is established, contact the repository owner through GitHub and request a private reporting route. Include the affected revision/component, impact, and safe reproduction steps. Do not include real secrets or personal data.

## Security expectations
- Never commit secrets or signing keys.
- Review privileged permissions and third-party components.
- Track upstream security updates.
- Test security-relevant behaviour and document limitations.
- Do not install experimental builds on devices containing important data.
- Establish signing, update-integrity, and recovery procedures before distribution.

No stable release or supported-version policy has been established yet.
